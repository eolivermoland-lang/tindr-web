What Tindr is, in slightly more detail.

This is a short public account of the project, not the full engineering log. It stays with what is already true, and it marks planned work as planned.

Tindr started as a blank repository. There is no Linux kernel under it, and no borrowed desktop. The first milestone built the toolchain, the documentation skeleton, and a test runner that boots QEMU headless on x86-64 and AArch64 and reads a pass or fail line from the serial port.

The second milestone put a picture on the screen: a UEFI loader, a kernel written in Rust, a serial log, a boot screen, and a panic screen. The official mark and Fjord Sans are drawn by Tindr's own rasteriser, not by a guest library inside the kernel.

Milestone 2, now tagged, gave the kernel its own memory and its own interrupts: a frame allocator, a heap, page tables with write xor execute, exception vectors, and a timer. Milestone 3, now underway, moves the kernel into the higher half and introduces Weaves and syscalls.

"Done" means an automated test proved it in QEMU on x86-64 and on AArch64. Screen tests compare a dump of the framebuffer with a golden PNG, with zero tolerance. Host unit tests and fuzzing cover parsers and allocators before they ever boot.

The usual commands in the operating system repository are just check, just test, just ci, just run, just bench and just image. This website is a separate project and does not build the kernel.

Tindr is licensed under Apache-2.0. Every source file carries an SPDX header. The official mark and Fjord Sans are designed by Oliver Torden and licensed with the project. Tindr Sans is the system's fallback face when a glyph is missing.

This site self-hosts Fjord Sans and uses a system sans as a fallback for the few characters the typeface does not yet contain.
