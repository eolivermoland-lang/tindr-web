# Fjord Sans

The primary typeface of Tindr, designed by Oliver Torden in 2026. He owns
the typeface and licenses it with the project under Apache-2.0.

The site self-hosts three cuts as WOFF2, with the original OpenType files
kept beside them:

- Thin (100), for large display sizes
- Regular (400), the body default
- Bold (700), for titles and the wordmark

The family currently contains 90 glyphs of Latin, Norwegian letters (ÆØÅ
æøå), punctuation and figures. Missing characters fall back to the system
sans in the font stack.

These files are first-party. They are not a third-party webfont.
